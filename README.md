# Passgen

Консольный генератор паролей на Python.

## Возможности

- Выбор длины пароля
- Использование латинских букв
- Добавление цифр
- Добавление специальных символов

## Запуск программы

```bash
py main.py
```

## Запуск тестов

```bash
py -m unittest test_main -v
```

## Используемые технологии

- Python
- Git
- GitHub
- unittest
## Автоматическое тестирование

Для проверки работоспособности программы используется GitHub Actions.
Тесты автоматически запускаются при внесении изменений в проект.
